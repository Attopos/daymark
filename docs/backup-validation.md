## 本次修复

1. 恢复时将全部元数据字段登记为新本地修订，修复空库首次同步及同值覆盖时被旧云端记录反覆盖的问题。
2. 导出和导入预检实际解码图片，拒绝只有合法文件头、CRC 或哈希却无法读取像素的损坏图片。
3. 已排队云端删除的旧 ID 不再复用于新恢复条目，避免在途删除误伤恢复后的记录。
4. 日期键固定使用公历并保留时区语义；拒绝与存储日期明显矛盾、无法判断来源历法的旧日期键。

原有云端删除测试已通过可注入回调隔离；应用默认的删除同步行为保持原样。

## 备份范围与精度

- 导出覆盖**当前打开的资料库**。登录资料库和未登录资料库分开，需要分别导出。
- 缩略图和浏览图从原图重建；登录凭据、主题偏好及同步过程状态不属于日记备份内容。
- 记录中的时间戳采用毫秒精度；原图内的 EXIF 信息随原图字节完整保留。
- 本次未读取个人实际备份文件，也未验证真实 iCloud/Google Drive 账户的网络传输或真机升级安装。
